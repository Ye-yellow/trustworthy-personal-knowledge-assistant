# Security Policy

## Private data boundary

This is a public source repository. Never submit real vault content, personal notes, attachments, credentials, databases, vector indexes, model caches, logs, traces, screenshots, or private evaluation data.

Use synthetic fixtures for tests and documentation. Redact usernames, local absolute paths, private URLs, tokens, and any personally identifiable information before creating a commit, issue, or pull request.

## Reporting a vulnerability

Do not disclose credentials, personal data, or exploitable details in a public issue. Use GitHub private vulnerability reporting when it is available for this repository.

If a secret is committed, revoke or rotate it immediately before attempting history cleanup.
